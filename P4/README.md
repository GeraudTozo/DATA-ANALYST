# 📊 Projet 4 – Analyse des écarts de performance


## 🧩 Contexte

L’entreprise cherche à analyser les différences de performance du personnel. Elle souhaite déterminer si ces écarts sont statistiquement significatifs, et identifier les facteurs RH qui influencent la performance.

- Identifier si certains départements performent mieux ou moins bien.
- Explorer les facteurs associés à ces écarts : genre, poste, satisfaction, heures travaillées, salaires, etc.
- Utiliser des tests statistiques pour valider ces différences.

---

## 🛠️ Méthodologie

| Étape | Action effectuée                                  | Objectif |
|-------|---------------------------------------------------|----------|
| ✅ 1.  | Nettoyage des données                            | Préparer un dataset fiable |
| ✅ 2.  | Profilage des employés                           | Comprendre la population interne |
| ✅ 3.  | Analyse des variables qualitatives               | Identifier les sources d’écarts |
| ✅ 4.  | Analyse des variables quantitatives              | Identifier les facteurs associés à la performance |
| ✅ 5.  | Tests statistiques                               | Vérifier la significativité des différences |

---

## 🔎 Résultats clés

### Profil des employés
- Répartition homogène par genre, poste et département
- Population expérimentée (30–60 ans), avec forte stabilité (5–10 ans d’ancienneté)
- Bonne base pour des comparaisons statistiques

### Tests statistiques
- **Aucune variable qualitative (genre, diplôme, département, poste) n’explique significativement la performance**
- Les différences observées sont donc probablement liées à des **facteurs individuels ou quantitatifs**

### Analyse quantitative
- **Le salaire est la seule variable corrélée positivement à la performance**
- Aucun lien significatif avec les heures travaillées, l’âge ou la satisfaction

---

## Conclusion

Cette étude révèle que :
- La structure organisationnelle **n’a pas d’impact direct** sur la performance individuelle
- La performance semble **reconnue et valorisée via la rémunération**
![Haut performeur](Boxplot.png)

- Les autres facteurs traditionnels (heures, satisfaction) n’ont **pas de poids statistique mesurable**

## 💡 Recommandations

- Auditer la **politique salariale** pour garantir une équité basée sur la performance
- Étudier les parcours internes pour mieux relier **promotion / ancienneté / performance**

### Données :
